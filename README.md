## ★ &nbsp;The flagship — AgentHost

> **Everyone sells a more capable agent. I sell the layer that decides what an agent is allowed to do.**
>
> One command moves your Claude Code setup to a 24/7 box in **your own** Fly.io account. Six engines from six different companies share one board — so the one reviewing code is never the mind that wrote it — and the irreversible stuff (deploy, spend, send, delete, credentials) always waits for a human. The governance layer is patent pending (two US provisionals).
